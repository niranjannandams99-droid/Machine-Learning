## Projects

### 1. MovieLens Rating Prediction System
Predicting user movie ratings using engineered user and movie statistics.

**Techniques Used**
- Feature Engineering
- Correlation Analysis
- Linear Regression
- Ridge Regression
- Decision Tree Regressor
- Random Forest Regressor
- Gradient Boosting Regressor
- XGBoost Regressor

**Performance**
- Best Model: XGBoost
- RMSE: 0.9126
- MAE: 0.7180
